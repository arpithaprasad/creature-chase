# The Great Creature Chase: AR targets

Image targets for the classroom version of The Great Creature Chase, an AR scavenger hunt built with A-Frame and MindAR (INFO 680, Pratt).

- `art/placeholders/T00.png` … `T08.png`: stand-in artworks, in target order (poster, six footprint cards, graffiti mural, chair card). They'll be replaced with the final art.
- `art/placeholders/targets.mind`: the nine placeholders compiled for MindAR 1.2.5.

The app loads `targets.mind` through jsDelivr, pinned to a commit.
